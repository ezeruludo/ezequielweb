EZEQUIEL AGUILERA — SITIO WEB

ARCHIVOS:
- index.html = estructura y contenido
- style.css = diseño
- assets/ = CV, fotos y otros archivos

PARA PERSONALIZAR:
1. Abrí index.html y reemplazá los textos de ejemplo.
2. Poné tu CV PDF en assets/cv.pdf.
3. Agregá fotos en assets/ y reemplazá el bloque de imagen de la sección Fotografía.

PUBLICACIÓN GRATUITA:
La opción recomendada es GitHub Pages. Subí estos archivos a un repositorio y activá Pages desde Settings > Pages.
Luego se conecta el dominio ezequielaguilera.com.ar desde la configuración de GitHub y NIC.ar.

IMPORTANTE:
Las tipografías se cargan desde Google Fonts. Si preferís máxima independencia, después podemos alojarlas localmente.
